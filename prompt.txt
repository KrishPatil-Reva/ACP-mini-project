"Develop a menu-driven 2D Graphics Editor in C language using arrays. The program should provide a canvas of fixed size and allow the user to draw basic shapes such as Line, Rectangle, Triangle, and Circle. Implement functions for canvas initialization, displaying the canvas, drawing points, drawing lines using the DDA algorithm, drawing rectangles, triangles, and circles using the midpoint circle algorithm. Include options to display the canvas, clear all drawings, and exit the program. Use a character-based graphical representation where drawn pixels are marked with '*' and empty spaces with '_'. The program should be interactive and menu-driven."
